# believe × Biomarker 평가 결과 (통일 framing)

## 설정
- **데이터**: OncoKB 스타일 바이오마커 연관 중 drug 있는 **1,122건** (치료 959 + 내성 163).
- **가설(통일)**: 모든 건을 동일하게 **"이 약에 반응한다"** 형태로 만듦.
  `In {cancer}, {gene} {alteration} predicts response to {drug}.`
  - **치료 (level 1·2·3A·4)** → 참 명제 → **SUPPORT 기대**
  - **내성 (R1·R2)** → 실제로는 약이 안 듣고 내성이므로 → 이 가설은 거짓 → **REJECT 기대**
- **파이프라인**: 가설로 qwen 검색(top-1000) → 각 abstract를 LLM이 SUPPORT/REJECT/NEUTRAL 판정 → top-K에서 다수결.
  - retriever `Qwen__Qwen3-Embedding-0.6B`, LLM `openai/gpt-oss-120b`
- **다수결**: top-K 중 support > reject → 그 건의 결론 = SUPPORT, reject > support → REJECT, 둘 다 0/동수 → none.

## 핵심 발견
1. **근거 수준(level)을 그대로 반영** — 치료 연관의 SUPPORT 결론율: **Level 1(57%) > 2 ≈ 3A(31~40%) > 4(12~15%)**. 강한 근거일수록 더 잘 확인.
2. **Level 4는 사실상 음성처럼 행동** — K가 커지면 SUPPORT(12%)보다 **REJECT(62%)가 우세**. level 4는 임상이 아닌 생물학적/전임상 근거라, 임상 문헌이 뒷받침하지 않음.
3. **내성(R1·R2)은 거짓 명제로서 정확히 기각** — "반응한다"에 REJECT가 K 커질수록 압도(R2는 K1000에 **100%**). believe가 약효 방향성을 이해.
4. **K(검색 깊이)의 효과** — 치료는 K≈25~100에서 SUPPORT가 정점 후 정체(하위 논문이 REJECT 추가). 내성은 K 커질수록 REJECT가 단조 증가.

### Feature importance (per-value)
필드 단위(변이/암종)가 아니라 **개별 값**이 판정에 얼마나 결정적인지 (그 값을 일반화/제거했을 때 net-support 점수 변화량, top-1000):

- **가장 중요한 변이 = 구체적 점돌연변이**: `T790M`(EGFR 내성, Δ0.50), `Wildtype`(Δ0.42), `G1202R`(ALK 내성), `S768I·L861Q·G719·L858R·Exon19`(EGFR), `V600K`(BRAF), `T315I`(ABL1 내성), `MSI-High`. → 임상적으로 결정적인 변이들이 그대로 상위. 반면 `Oncogenic Mutations`·`Pathogenic Variants` 같은 **클래스 라벨은 중요도 하위**(일반화해도 의미 거의 안 변함).
- **암종 중요도는 전반적으로 훨씬 낮음**(최대 0.23 vs 변이 0.50): 희귀암(췌장 acinar, 자궁육종, IMT)만 다소 높고, 흔한 암(유방·전립선·대장)은 0.03~0.06로 미미.
- 방향: 대부분 변이를 빼면 support↑(빨강) — 특정 변이가 "내성/특이성"을 담아 주장을 제약하고 있었음을 의미.

→ **believe의 판정을 가르는 핵심 feature는 개별 (특히 내성·활성화) 점돌연변이이고, 암종 맥락과 변이 클래스 라벨은 영향이 작다.**

### Context 기여도 결론 (ablation)
- **변이(alteration) = 결정적 context**: 내성 reject% 97%→17% (일반화 시 붕괴). 유전자별로도 ALK·KIT·ROS1·ABL1은 변이 빼면 reject 0~몇%로 추락.
- **암종(cancer) = 거의 무관**: 암종만 빼도(A2) 내성 reject 94% 유지.
- **치료**: 일반화할수록 support 증가(A0 41%→A3 73%) — 넓은 주장이 뒷받침 문헌을 더 쉽게 얻음.
